# IL27 pilot course facts

As Flavia stated them, October 2026, updated on 4 Nov 2026 from the IL27 context update. Update this file when the course changes, and don't infer facts that aren't here.

## The course

- **What it is:** a pilot of the Innovation Labs 2027 strategy for tech master's students. Ana co-runs it.
- **Eight classes, all counted as modules:**
  1. Ideation, 21 Oct
  2. Persona and customer discovery, 28 Oct
  3. Journey mapping, 11 Nov
  4. Experiments, 18 Nov
  5. Business model and competition, 25 Nov
  6. AI prototyping and user testing, 2 Dec
  7. Pitch prep, 9 Dec
  8. Evals and pivoting, 16 Dec
- **Other dates:** a field week on 4 Nov, build-track feedback on 13 Jan and the final review on 20 Jan.
- **Class length:** every class is scheduled for 3 hours, and the team tries to finish under 3. Build teams also work on their project between classes as homework.
- **Tracks:** the theory track passes on the exit outputs handed in. Session timing can differ from other IL programs.
- **What it drives:** students get better prepared for the real world. The skills from the 8 classes are something they can add to their CVs. The student deck shows this up front, with the passport and the full schedule.

## The loop

The loop is shown at the start of every class: **think in analog, challenge with AI, human synthesis.** Students work on paper first, then challenge it with the module's challenger skill, then decide themselves what to keep.

## Skills and the exit ritual

- Every class has a challenger skill and an exit skill (see `course-skill-pair-maker`).
- The exit skill summarizes the results and keeps the challenger transcript, how the skill behaved and how the student went through the loop.
- Photos of the paper work are required in every challenger and exit. The challenger does not start without them.
- The skills never grade.
- **Exit file (decided 28 Oct, from Module 2 on; replaces the zip):** one exit file per team, saved and emailed by one team member to contact@tech-lounge.ro. It is one plain .txt (no zip, no Word, no RTF), named `IL27_M1_`, `IL27_M2_` or `IL27_M2F_` (field track) plus `Surname_Firstname`. The subject is `IL27 M2 | Surname Firstname` (field track: `IL27 M2 FIELD | Surname Firstname`), the email body stays empty, and every teammate's name is inside the file.
- **Latest recorded skill versions (28 Oct, confirm with Flavia):** Module 1 challenger and exit `m1-v0.2`; Module 2 challenger and exit `m2-v0.3`; Module 2 field track pair `m2-field-v0.2`. Each exists as a skill zip plus a prompt .md. The copies archived in `course-skill-pair-maker/references/` are the older v0.1 versions.
- **Field track (going for a 10):** real interviews, then four photos: the interview log, the marked guide, hypotheses with verdicts and guide version three. The field challenger runs who did you talk to, evidence check, interview replay and guide check.
- Students are not in the organization, so downloads from artifacts don't work for them. The skill .zip and prompt .md files live in a public Drive folder per module, and the deck links there. Check that the folder is set to "anyone with the link can view" before linking it. Module 1's folder: https://drive.google.com/drive/folders/1EBHzr7upsEcf8vc6ipLJ-MF2i8X1usTn

## Open decisions

Open questions (for example how many interviews count for a 10, or a Moodle deadline) are tracked in the Project's IL27 context file. Don't assume an answer, and don't put an undecided number or date into a deck or message.

## Module notes

- **Module 1, 21 Oct, "Finding a solution for a problem, not a problem for a solution":** define one problem first, then sketch solutions on paper without building them. Solutions aren't always an app. Interviews belong to Module 2.
- **Module 2, 28 Oct, customer discovery:** built on Flavia's 11 Sept VSFA customer discovery deck. Balloons as bullets and throughout, several examples shown with a shuffle, step-by-step slides and interactions to dig deeper. Her original VSFA pages (the Instagram, YouTube, TikTok and Airbnb stories, persona examples, problem statement template, pricing hypothesis example and Mom Test sketchnote) were restored as full slides in their original style (28–30 Oct). Another session also edits this deck: read the live version before changing it.
- **The "Who am I" slide** uses the wording from Flavia's customer discovery deck.
- **Candidate problems:** students see only the problem and who has it, from the problem market (15 challenges).
